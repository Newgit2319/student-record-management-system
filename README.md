# Student Record Management System

A Python-based application to manage student records using SQLite database.

## Technologies Used
- Python
- Flask
- SQLite
- HTML

## Features
- Add Student
- View Students
- Search Student
- Update Student Marks
- Delete Student
- Input Validation
- Database Timestamp Tracking
